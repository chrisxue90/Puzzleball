# 彩色小连珠后端

这是与微信小游戏独立部署的自有服务器后端边界。当前只提供健康检查，尚未接入账号、云存档、排行榜或数据库。

## 本地启动

在仓库根目录运行：

```bash
pnpm dev:backend
```

默认监听 `http://127.0.0.1:8788`，健康检查为 `GET /health`。可复制 `.env.example` 中的变量到自己的运行环境，但不要提交真实密钥。

## 生产要求

- 使用 HTTPS 域名，并在微信公众平台配置为 request 合法域名。
- 在服务器环境变量中管理数据库密码、AppSecret 和签名密钥。
- 不信任小游戏上传的分数；排行榜接口必须做身份、重放、频率和游戏结果校验。
- 记录隐私相关数据前，同步更新隐私保护指引和数据保留策略。

微信开发者工具只导入仓库根目录下的 `wechat-game/`；本后端目录不会进入微信小游戏代码包。
