# 微信小游戏与共享核心需求

## 目标

将微信端改造成可直接导入微信开发者工具的微信小游戏，并让网页版与小游戏使用同一份游戏规则源码，消除手工复制和漏打包风险。

## 验收条件

1. 当开发者从干净仓库导入 `wechat-game/` 时，微信开发者工具必须能识别 `game.js`、`game.json` 和小游戏 AppID 配置。
2. 当任一客户端执行移动、寻路、连线、生成球或计分时，必须调用 `wechat-game/shared/game-core.js` 中的同一规则实现。
3. 当小游戏代码出现越出 `wechat-game/` 的运行时依赖时，自动检查必须失败。
4. 当共享规则发生变化时，规则测试、网页构建和小游戏静态检查必须在 GitHub CI 中同时通过。
5. 当用户直接点击开发者工具“上传”时，所有游戏运行代码、配置和本地资源必须已经位于 `wechat-game/` 内，无需预先复制文件。
6. 后端必须继续独立部署，不得进入小游戏代码包。

## 不在范围内

- 不接入登录、广告、支付、联网排行榜或云开发。
- 不改变现有网页视觉方向和已确认的基础玩法。
- 不执行微信后台提审或正式发布。
